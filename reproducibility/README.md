# Half-car suspension research — reproducibility package

Source code accompanying the manuscript **“Passive and LQR-Controlled Active Half-Car Suspension: Ride Comfort, Road Holding and Robustness with a Realistic Actuator and Observer.”**

## Contents
- `hc.py`, `real.py`: half-car model, LQR, actuator/observer and Wk weighting.
- `run_base.py`, `run_mc.py`, `run_real.py`, `run_washout.py`: numerical experiments.
- `figs.py`, `eqs.py`: figure and equation-image generation.
- `run_all.sh`: prescribed execution order.
- `requirements.txt`: package versions.
- `INDEPENDENT_EVALUATION_README.txt`: road-seed protocol and interpretation notes.
- Archived JSON outputs and matrices are provided alongside the scripts.

## Reproduce
Use Python 3.12.10 or a compatible Python 3.12 release. From this directory:

```bash
python -m pip install -r requirements.txt
bash run_all.sh
```

The run script regenerates `results.json`, `results2.json`, `results3.json`, `mats.json`, `figs/base.npz`, and figure files under `figs/`. Runtime depends on hardware; the project notes estimate approximately 10–15 minutes.

## Evaluation protocol
Controller tuning uses road seeds 1000–1007; held-out random-road evaluation uses seeds 2000–2019. The Class B/Class C comparison uses matched seeds and a fourfold PSD parameter, so it is a paired amplitude-scaling comparison, not independent road-class validation. See the evaluation note.

## Scope and limitations
This is a Python simulation implementation, not the original Simulink model and not experimental vehicle data. Wk-weighted acceleration is evaluated at the vehicle-body centre of gravity, not at a seat. Results should be checked against the exact manuscript tables and figures before treating this archive as a final immutable release.

## Archived outputs
The archived `results2.json`, `results3.json`, and `mats.json` are supporting outputs from the project workspace. The full output set, including `results.json` and generated figures, is regenerated by `run_all.sh`. Generated figure files are not included in this source commit.
